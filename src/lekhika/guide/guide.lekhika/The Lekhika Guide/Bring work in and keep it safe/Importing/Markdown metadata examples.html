--- title: Markdown metadata examples kind: scene page_break: auto ---

When preparing markdown for import, you can add a type hint in parentheses after a metadata field name to set how Lekhika stores and shows that field. If you omit the hint, Lekhika assumes text (or keeps an existing field's type).

Allowed type hints

  • text — plain text
  • text area or textarea — longer text shown in a text box
  • checkbox — true/false value
  • date — date value (use ISO format YYYY-MM-DD)

Example YAML block for a scene

---
PoV (text): Aaxyl
LoC (text): SYMBTech building
Vegetarian (checkbox): true
Due (date): 2026-11-14
Quote (text area): Blah blah blah, bleh bleh bleh, much much words etc etc etc for a few sentences to appear in a text box.
---

Put this block above the heading or content for the document it describes. Use the values you want imported: checkbox fields accept true/false (also yes/no), and date fields should use YYYY-MM-DD. If a type hint is missing or unrecognised, Lekhika imports the field as text and you can change it later.
