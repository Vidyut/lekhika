File → Import Markdown… reads a markdown file and makes documents out of it. Markdown import can read Lekhika’s own markdown export format (markdown with a YAML block above each heading) and markdown exported from other writing software, as long as the file is structured clearly enough for Lekhika to read.

For the smoothest result, export your work as one markdown file in the correct sequence. Lekhika can split that file into documents by headings and build a tree from it. If your source project has metadata you want to keep, include it in YAML blocks so Lekhika can read it as fields. World-building material such as character, location, item or story-arc notes can be imported as regular content documents in the same way.

File → Import from Lekhika Project… lets you bring folders or documents from another Lekhika project into the current one. Choose the source project, select what you want to import, and Lekhika copies it into the current project (under the selected container, or at the top level) with its structure, order, content, metadata, type and template information.

Imports land under whatever you had selected in the binder — or at the top of the tree when you had nothing selected.
