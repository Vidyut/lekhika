--- title: Your files are your files kind: scene page_break: auto ---

A Lekhika project is a folder on disk: your documents live in the folder tree, with files such as manifest.json, per-folder .order.json files, images/, templates/, trash/, and project.sqlite3 (used by Lekhika as an index). You can copy the folder, back it up, or keep it in version control like any other files.

If you ever need to access the project without Lekhika, the structure is readable: manifest.json records the root order, each folder’s .order.json records that folder’s sequence, and each document file carries its metadata as YAML in the head alongside the content. A regular file manager may sort files alphabetically or by date, but these files preserve the project’s intended order and metadata so your work remains accessible.

Backups go to a per-project backup location by default and can be scheduled (daily/weekly/on close); renamed backups are kept. Images live under the project in images/ and are referenced by the manuscript. Recent projects lists projects you have opened.
