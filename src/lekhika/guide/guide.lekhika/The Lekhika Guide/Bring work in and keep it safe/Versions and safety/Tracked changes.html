--- title: Tracked changes kind: scene page_break: auto ---

Tracked changes can be useful for collaboration, or when you want to review an edit later before deciding to keep it.

Content inserted or changed using the AI feature is always tracked, so you can accept or reject those suggestions.

Edit → Accept All Changes in Section and Edit → Reject All Changes in Section work on the document you are in. Revision Passes… keeps a set of named edits and works through them one at a time, so a pass of line edits can be handled deliberately rather than in one sweep.

Revision author is set in Preferences so tracked changes carry your name. Revision Passes… (Edit menu) keeps named passes over the manuscript so you can work through sets of edits deliberately.
