--- title: Backups kind: scene page_break: auto ---

Ctrl+S saves the project and can create a backup. A backup is a full copy of the project folder as it stands, stored outside the project.

File → Choose Backup Folder… sets where backups are stored. If you do not choose a folder, backups are placed in a Backups folder beside the project, in a subfolder named after the project. Keeping backups outside the project means they are not lost if the project folder itself is deleted or damaged.

You can choose how often automatic backups are made in Preferences → Files & saving (for example on close, hourly, daily, weekly, every save, or never automatically). If you use Ctrl+S out of habit, a less frequent schedule can help avoid filling your backup folder with many near-identical copies.

Backup copies are named with timestamps. Lekhika avoids creating a new timestamped backup when nothing has changed since the last backup, and it prunes older timestamp-named backups automatically. To keep a particular backup from being removed by automatic pruning — for example, one taken before a major change — rename it so it no longer follows Lekhika’s timestamp naming (for example, backup-1Dec2026).
