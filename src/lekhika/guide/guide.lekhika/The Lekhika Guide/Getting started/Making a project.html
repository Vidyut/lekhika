--- title: Making a project kind: scene page_break: flow ---
  • A project is a folder Lekhika keeps for one manuscript.
  • File → New Project… asks for a place to keep the files and a title.
    • The title is the project's own name, and a template can print it with $${Project}.
    • Whether it appears in an export at all is up to the template.
  • A new project starts with one empty folder, called Draft.
    • Everything you add goes inside it: chapters, scenes, notes, and other folders.
    • That first folder is not special — you can rename it, move things into it, or delete it once you have somewhere better to put them.
  • For ease of use, consider making separate folders for what you intend to publish — books, essays, papers — and for other things: research, world building, characters, locations.
    • Inherited templates make configuring very easy: set the template for the whole folder and there is nothing more to do.
    • Only documents are exported, so stray research cannot slip into an export.
  • The software will export the documents you select and leave the rest out, regardless of how complex your document organising gets.
