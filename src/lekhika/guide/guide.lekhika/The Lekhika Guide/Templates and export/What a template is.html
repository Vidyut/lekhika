--- title: What a template is kind: scene page_break: auto ---

A template decides how an export looks. It is a folder of fragments — small pieces of HTML — plus a print configuration file, and Lekhika reads them to dress your manuscript.

You do not have to write one. Five sets ship with Lekhika, listed under View → Template Sets:

  • default — the ordinary book: title, prose, pages.
  • short story — a unit-dressed collection on A4.
  • Book — one page per kind of thing, named after the Type it dresses.
  • Guide — a manual: a shaded heading page and a section page, the two Types this guide is written in.
  • no-export — prints nothing at all. It is there to keep a folder out of an export, and to show that silence is a valid answer.

They live in the software, so there is nothing on disk to edit. Right-click one and choose Duplicate into project… to get an editable copy in your own project.

A set can dress one format differently: a subfolder named epub, html, docx, pdf or text overrides the parent set for that format only. A document can name its own document template in the inspector to override the set. The Templates view (View menu) lets you edit templates; the CSS editor writes the set's style.css for HTML and EPUB.

Scope for export can be the whole project, a folder, or a selection (folders expand). no-export keeps a folder out of an export.

A template's configuration can also declare Folder types, Document types and Required metadata fields: <Type>: <Field,...>. When you assign the template, Lekhika adds the declared types to the project and adds and marks the declared fields as required for matching document types. The Book template, for example, requires BookTitle and Author for the Book type.
