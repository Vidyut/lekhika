--- title: Page setup kind: scene page_break: auto ---

The book folder's Page setup button is where paper lives: page size or a named trim, the margins, mirroring for a book, and the gutter at the spine. Set it on the book folder — the nearest one above the document wins, so a series folder can give all its books one trim. Where pages begin and what the running heads say are not in this dialogue: those belong to the template's design, in the template panel.

A template's own configuration overrides page setup, and page setup overrides the built-in A4 — so you can set the trim once for the project and let a template change it only when it has an opinion.

The running heads and feet read placeholders. A line like Header right: , ,$${PageNo} puts the page number at the right of every page. $${PageNo} is a position, not a count: Word or LibreOffice fills the number in, so it stays right as the text reflows. You can also put $${PageNo} on a line of its own in the text, and the export writes the number at that spot. Formats with no fixed pages — HTML, EPUB and plain text — print nothing for it.

$${BookTitle} is metadata driven. A folder export uses that folder's BookTitle metadata, and a whole-project export uses the project's own BookTitle metadata. If it is unset, or there is no book for that export, it prints nothing — nothing is invented to fill it.

A running head on a chapter's opening page usually looks wrong, and most books leave it off. Header first page: none says so; Header first page: , ,$${BookTitle} says the opposite, an opening page with a head of its own. The footer has the same pair. These lines speak for each section's opening page — every chapter, where chapters start a new section.

Running heads are often set smaller than the body. Head font: Georgia, 9 gives the header, the footer and the page number their own family and size, and leaves the body's typography alone.

Page size accepts inches, millimetres, named sizes (such as A4) or values like 5x5. A divider between child documents (in page setup) can print a separator such as * * * between children of a folder, or nothing at all.

print-config.txt in a template overrides page setup; a sample .docx supplies the rest. Page setup applies only where the template is silent.
