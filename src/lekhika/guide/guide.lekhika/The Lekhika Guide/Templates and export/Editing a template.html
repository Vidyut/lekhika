--- title: Editing a template kind: scene page_break: auto ---

The easiest way to make a new template is to duplicate a default set in View → Template Sets, open the copy, and make the changes you need. A fragment is HTML with placeholders in it:

<p class="chapter-title">$${Title}</p> <div class="children">$${children}</div>

$${Title} is the document's title. $${Content} is its prose. $${children} is everything inside it, each child dressed in the template that applies to it, in the order you arranged them. Naming the children is optional: an export always walks the selection in order, so a fragment that never mentions them has them printed right after itself. The placeholder is for positioning — a chapter that should carry a closing note after its scenes puts $${children} first, then the note.

The Placeholders… button in the template panel lists every name Lekhika knows, with what each one means — including the fields of your own project and the Types in it. It is also how a name gets written: click one and it lands, complete, at the cursor of the box you were in. Typing the placeholder also works. The buttons are merely to prevent errors that may prevent the correct insertion of the data.

If you spell a name wrong, the template still saves and Lekhika tells you: this template names a placeholder Lekhika does not know. Saving anyway is deliberate — a template can be written before the document or the field it names exists. At export, a placeholder that still has no value prints nothing: the name is removed and replaced with nothing.

As well as the config box, the panel gives the page's print settings as fields — they shape DOCX and PDF exports. Page size, margins, mirror margins and page start are rows you pick from. Below them, the Header and footer rows hold the running head and foot as the three places a piece can sit — left, middle and right. A pick above them says which pages the rows are speaking for: the Main body, the Facing pages (even) that a mirrored book prints differently, or the First page, each section's opening page — the one a chapter opener usually leaves bare. A row you leave empty keeps the sample's own head; tick None and these pages carry no head at all. Each row writes one Header: or Footer: line into the config box, so the box stays the truth and nothing is hidden behind the fields. Below the rows, Header and footer font writes the running heads' own family and size as a single Head font: line, for the header and the footer both; left alone, the sample's own head stands. If you never export for print, you can safely ignore these fields.
