Six themes ship: System (desktop), Light, Rose (dusky red), Earth (ochre/olive), Dark (grey sky) and Night rose. System follows your desktop light/dark; the rest are fixed palettes — there is no colour picker, because a theme you can fiddle with is a theme you have to fiddle with.

Pick one in Preferences. The accent colour belongs to the theme, and so do the button faces and the scrollbars: nothing is left in the colour it had before you switched.

Interface font size is also configured in Preferences → Appearance, alongside the theme, so you can adjust the app’s interface text and appearance together.
