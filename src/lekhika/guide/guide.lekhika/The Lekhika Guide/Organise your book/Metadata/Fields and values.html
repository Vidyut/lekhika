--- title: Fields and values kind: scene page_break: auto ---

Metadata is the information about a document: its status, whose point of view it is, when it happens, whether you have finished it. Lekhika keeps it in a small table under the text, and you decide what the fields are.

To add a field: select the document, and in the inspector's Metadata panel press Add. Type a name — Status, POV, Date, Word target, Location, anything — and it becomes a field of that kind of document. Every other document of that kind now offers the same field, empty, waiting.

These fields can be used as placeholders in templates by wrapping them in curly brackets and prepending with "$". So, if your metadata has a field called PoV and its value is "My Awesome Hero", you could use the field to create your title in the template. For example: <h3>$${PoV}</h3> and the exported file will have the title "My Awesome Hero". If another scene has the PoV: "Villain guy" the title for that scene will become "Villain Guy" - these replacements are only done during the export and within the software itself, you will see fields and values in the metadata, and placeholders in the templates.

Your fields are yours to keep. Lekhika reads them from the project's own database while you work, because that is what makes it quick, and it also writes them into each document's file — a small block at the top of the file, above the prose. So the information is in your hands twice over: in the project, and in the document itself, where any text editor can read it and where it stays with the writing even if the project folder is moved, copied or opened by another tool.
