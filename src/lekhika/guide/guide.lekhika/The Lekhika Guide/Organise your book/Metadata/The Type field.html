--- title: The Type field kind: scene page_break: auto ---

One field is protected: Type. It is the document's role (Folder, Document, or a name of your own), and it is what templates dress. It cannot be edited away by accident, and it is never exported as ordinary metadata — it is the book's structure.

Metadata is managed by type. Create a field on one document of a type and it becomes available on every document of that type, empty and waiting. A Recipes type with an Ingredients field shows that field on every recipe document, and a recipe template can read it; a plain document with no type never shows it and never uses it. So the type you give a document decides which fields belong to it.
