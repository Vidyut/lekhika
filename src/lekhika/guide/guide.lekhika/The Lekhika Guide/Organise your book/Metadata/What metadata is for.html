--- title: What metadata is for kind: scene page_break: auto ---

Mostly three things:

  • Keeping track. A Status field with Draft, Revising, Done turns the binder into a progress report.
  • Printing. A template can ask for any field, so an epigraph, a point of view, a date or a quotation can appear on the page without being typed into the prose.
  • Finding. The project-wide search covers metadata as well as prose, so POV: Jack finds every scene that is his.

The content of a book can use metadata and placeholders too. If you haven't named your villain, you could write your story with $${Villain} and when you decide on the name, add the field "Villain" to the project-wide metadata and it will be replaced during export. If you want the replacement to happen in the project text, you will have to use search and replace.

Or, if you want to use tags on a scene and then print them in the text, you could do that. Field called "tags" in the metadata, placeholder $${tags} in the document. Just remember that placeholders are processed during export.

Metadata applies to a type of document. So if you add a metadata "PoV" to a scene type document and "Plant" to a nursery document, the nursery document will not show PoV and the scene won't show plant, but all nursery type documents will have an empty field for plant until you fill it. And all scene type documents will have "PoV" fields.

The inspector's metadata panel follows the selection: select a document or folder to see and edit that item's own metadata. With nothing selected, the panel shows the project's own metadata. In a full binder, click the selected item again (without Ctrl or Shift) to deselect it and reach the project metadata.

A metadata field with a textarea type has an editable box below the metadata table as well, for both documents and folders, so longer text is easier to write. Edit Metadata (Document menu) opens the full metadata editor for the selected item. Known fields are remembered per group (folder or document type), so a field you create shows up on other documents of that group. Outliner Columns (Document menu / outliner) lets you show metadata columns in the outliner to scan by status, POV or any metadata field.

Media (inspector) lets you attach images to a document; they are copied into the project and shown as thumbnails. Cover can be set on folders in the inspector (auto-detects images/<folder_id>/cover.* if left empty).
