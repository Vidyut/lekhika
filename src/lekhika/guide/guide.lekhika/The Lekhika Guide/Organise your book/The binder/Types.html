--- title: Types kind: scene page_break: auto ---

Every document has a Type: Folder, Document, or a name you make up (Leaf, Poem, Interview, Chapter, Scene — whatever suits your book). The Type is what templates dress and what you filter by.

If you have selected a folder or document, the dropdown will offer types applicable to it. Using existing types and creating new ones only when you need new kind of formatting helps keep the export formatting manageable. By default there is one type for folders (Folder) and one for documents (Document). If your text is straightforward and does not need custom formatting of different types, you can simply customise the folder and document templates - this is great, because it removes the need to assign types and templates.

You can use the text box to add a new type. Once a type is created for a folder, it will show up for all future folders. And the same with documents.

To apply templates to types automatically, your template should have the same name as the type. For example, if you have a type called "recipe" and your template contains a template formatting document called recipe.html - it will automatically be used to format exports for the recipe documents.

You can override this assignment by explicitly selecting a desired template in a document's metadata. For example, if you have most recipes formatted in a certain way, but one needs to be handled differently, you can select a different template for it in its metadata and it will override the automatic selection for that document.

A document that should not appear in an export at all can be given the no-export template (or the no-export set), which prints nothing — without a separate kind to choose by mistake.
