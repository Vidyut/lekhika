--- title: Reading aloud kind: scene page_break: auto ---

Speak → Read Aloud (F8) reads the document you are in, in a system voice. F9 pauses and resumes, and Stop stops it.

The menu only appears when the feature is switched on: tick *Text to speech* in Preferences. Lekhak uses the voice your system already has — SAPI on Windows, NSSpeech on macOS, espeak on Linux — so there is nothing to install and nothing is downloaded.

It is genuinely useful for prose: hearing a sentence finds the awkward ones faster than the eye does.
