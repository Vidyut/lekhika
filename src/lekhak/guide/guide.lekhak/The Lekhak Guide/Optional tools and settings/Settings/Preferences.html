Edit → Preferences… (Ctrl+,) holds settings that belong to you or to this installation, rather than to a single document. The settings are organised by category.

Appearance
Theme and interface font size. See also Appearance in this section of the guide.

Editor
Spell-check and the dictionary used for your project’s words (including project scan / word-list support where available). If you are unsure about defaults, keep the standard settings.

Files & saving
Autosave, reopening the last project on start, backup location and backup frequency. Backups are extra copies stored outside the project; if you press Ctrl+S often, choose a less frequent automatic schedule to avoid many near-identical backups.

Pasting
Choose which formatting is kept when you paste (fonts and colours, paragraph formatting, bold/italics/underline, alignment). If you are unsure, leave the default paste settings. You can always paste as plain text when needed.

Links
How unpublished links are handled, and whether the Mentions / Mentioned by (Related files) scan is enabled. The mentions scan can be useful in some projects and distracting in others; disable it here if you do not need it.

Placeholders
The project-wide placeholder names and values available to exports and templates, along with the full placeholder reference for the current project.

AI and Read aloud
Optional features. Configure the AI endpoint/model and read-aloud voice/rate here. Enable or disable them according to whether you want those features available in your workflow.

Updates
Auto, Check, Manual or Nothing. Auto and Check look for a new version once per day (the first time Lekhak starts on that date). Manual (default) checks only when you ask, and Nothing makes no network call.

Help
Version and system details (including Copy system details for bug reports), where the program and settings live, links for issues/code/blog, and access to the manual. Copied details do not include your manuscript or project path.
