The editor is a rich-text editor that stores what you write as ordinary HTML. Select text and press Ctrl+I, Ctrl+B or Ctrl+U; use the paragraph style box for headings and body text; the alignment buttons do what they say. The usual stuff.

Images go in through Edit → Insert Image…: pick a file and Lekhak copies it into the project so the document travels with it. Alignment is the only layout on offer — inline, left, right or centre — because anything beyond that is a different kind of software. Left and right float the image with text flowing around it; centre puts it on its own line.

The word count for the document you're writing as well as the book update live in the bottom right status bar.


The unusual stuff are the buttons unique to Lekhak. If you have TTS configured, the "Read aloud" button will read your text aloud. If you have an AI configured, the "Proofread" button can check your text and suggest corrections as tracked changes that you can accept or reject. At no point will your text be altered without your knowledge.


What text is decided by this:

1. If text is selected, it will be read/proofread.

2. If you place your cursor in the text, from there onwards.

3. If no cursor is active in the text, the whole document.


Split at the cursor (Ctrl+K) splits a document. Undo/redo, find/replace, focus mode and zoom are all available; the editor remembers where you were.
