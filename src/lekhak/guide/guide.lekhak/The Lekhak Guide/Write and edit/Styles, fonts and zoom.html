--- title: Styles, fonts and zoom kind: scene page_break: auto ---

Paragraph styles live in the toolbar above the text. A style is a paragraph's role (Heading 1, Quote, Body Text); it is not a font setting, so changing the body font later does not disturb your headings.

You can create and update styles in the editor itself. If you select a text and right click, you will see options to set the style as default, create new styles, or update an existing style. You can't delete styles in the editor - you will have to go to preferences for that.

If you select unusual fonts in the editor, the export keeps them as named; the machine that opens the file needs those fonts installed. Please note, epubs uploaded to Amazon KDP may ignore formatting entirely or to various levels between the platform itself and the user's preferences - this is outside Lekhak's control.

Ctrl+plus and Ctrl+minus make the letters bigger or smaller for working in the editor without touching the font-size in the document at all (just like a browser). Ctrl+0 resets the zoom. This is the zoom you use for reading; it never becomes part of your formatting.
