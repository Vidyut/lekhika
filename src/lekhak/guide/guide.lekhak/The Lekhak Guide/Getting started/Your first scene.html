Press New Document (the button at the top of the binder, or the binder's right-click menu). A new empty document appears in a selected folder or after a selected file in the tree, and its title is selected. It is good practice to type a name straight away, as this will also name the file on your disk. If no name is typed, the created HTML will be named by the software, and you may not find it as easy to recognise if you decide to edit source files at a later date. Check to ensure the document appeared where you wanted it to. If a folder already has files, the new document may appear below them, but you may want it at a specific position. You can drag and drop to reorder and organise your project.

When you create the file, the page area in the centre automatically switches to the editor showing your new blank document.

Lekhak autosaves as you type, during pauses. You can close it at any time, and reopening brings you right back.

Ctrl+S saves the file intentionally (not really needed) and takes a backup. Backups are copies of the whole project kept outside it, so they survive even if the project does not; File → Choose Backup Folder… says where they go, and without it they land in a Backups folder beside the project.

Your word count for the document is in the status bar (bottom right of this window), with the reading time beside it, and the daily goal (if you set one) next to that.

Happy writing!
