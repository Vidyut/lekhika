--- title: Choosing what to export kind: scene page_break: auto ---

File → Export... asks two things: what to include, and how to dress it.

The scope is the selection in the binder, or the whole project if nothing is selected. You can select several folders and documents at once; the export takes them all, in binder order. Selecting a folder exports what is inside it.

The dialogue offers the template your content asks for. Assign a template in the metadata of a folder and everything below it inherits the assignment, until another folder overrides it; the deepest assignment inside the selection is the one offered. Export a chapter from a book folder and the book template's folder and document fragments still dress its scenes. The pick is a default you may change, and the change is one-off: the next export offers the detected template again. To make a choice stick, assign it to the topmost folder it should cover.

A set can dress one format differently from the rest. A folder inside it named after a format — docx, pdf, epub, html or text — applies to that format only, and the set's own files cover every format without one. So one set with a docx folder can print one design and hand EPUB another, from the same assignment.

Between the placeholders and the template a scope asks for, a book can be dressed in as much detail as it needs — and when nothing matches, the export is still valid: the default template's folder and document fragments print the selected material.
